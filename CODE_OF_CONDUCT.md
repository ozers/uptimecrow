# Code of Conduct

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- **Be respectful.** Disagreement is fine; personal attacks, harassment, and discrimination are not.
- **Be specific.** When you report a problem or critique a design, include details. "This is bad" is not a useful comment.
- **Assume good faith.** Most disagreements are misunderstandings, not malice.
- **Keep it on-topic.** GitHub issues, discussions, and PRs are for UptimeCrow. Political and religious arguments belong elsewhere.

## Scope

This Code of Conduct applies to all project spaces: this repository, GitHub Discussions, any official chat channel, and any event organized in the name of UptimeCrow. It also applies when you represent the project in public.

## Reporting

If you experience or witness behavior that violates this Code of Conduct, please email [conduct@uptimecrow.com](mailto:conduct@uptimecrow.com). All reports will be handled confidentially.

Maintainers are responsible for enforcement and may remove comments, commits, PRs, issues, and (in serious or repeated cases) ban contributors from the project.

## Enforcement

We use the [Contributor Covenant 2.1 enforcement ladder](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines): correction → warning → temporary ban → permanent ban, depending on severity and repetition.

The full text of the Contributor Covenant 2.1 governs in case of any ambiguity in this summary.
